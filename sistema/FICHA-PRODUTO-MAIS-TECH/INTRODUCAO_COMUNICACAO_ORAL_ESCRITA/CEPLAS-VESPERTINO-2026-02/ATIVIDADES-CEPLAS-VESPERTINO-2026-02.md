## ✍️ ATIVIDADE 1 — Mapa Mental de Ferramentas

**Tempo:** 30 minutos | **Formato:** ✋ Manual (no papel)

**Objetivo:** Você vai criar um mapa mental mostrando as ferramentas que aprendeu e como usá-las.

**Como fazer:**

1. **Pegue uma folha em branco (A4 ou maior)**
2. **No centro, desenhe um círculo grande** e escreva: "FERRAMENTAS DIGITAIS"
3. **Crie 4 galhos** (um para cada tema):
   - Google Workspace
   - Microsoft 365
   - E-mail Profissional
   - Organização de Arquivos
4. **Em cada galho, adicione sub-galhos** com as informações principais
5. **Use cores diferentes** para cada tema
6. **Adicione pequenos desenhos ou ícones** (opcional, mas deixa legal!)

**Exemplo de estrutura:**

```
                      📧 E-mail Profissional
                          ├─ Saudação formal
                          ├─ Corpo claro
                          └─ Assinatura profissional

        FERRAMENTAS 🖥️  ←→  Google Workspace
        DIGITAIS          ├─ Gmail
                          ├─ Drive
                          └─ Docs
```

**Critérios de avaliação:**
- ✅ Todos os 4 temas presentes
- ✅ Pelo menos 2 sub-informações por tema
- ✅ Bem organizado e legível
- ✅ Uso de cores/desenhos

**Prazo de entrega:** Final da aula

## ✍️ ATIVIDADE 2 — Simulação de E-mail Profissional

**Tempo:** 30 minutos | **Formato:** ✋ Manual (no papel)

**Objetivo:** Praticar escrever um e-mail profissional real.

**Cenário:**

Você é assistente de um gerente de uma loja de roupas. Precisa escrever um e-mail para o fornecedor de camisetas solicitando:
- 100 camisetas brancas (tamanho M)
- 50 camisetas pretas (tamanho G)
- Prazo: próxima semana
- Orçamento não pode passar de R$ 3.000

**O que fazer:**

1. **Pegue uma folha de papel**
2. **Escreva o e-mail à mão**, incluindo:
   - `PARA:` (nome fictício)
   - `ASSUNTO:` (claro e objetivo)
   - Saudação formal
   - Corpo do e-mail (3–5 linhas)
   - Fechamento profissional
   - Sua assinatura completa

3. **Revise antes de entregar:**
   - ✅ Tem todos os elementos?
   - ✅ A letra está legível?
   - ✅ Sem erros de ortografia?
   - ✅ Tom profissional?

**Exemplos de erros COMUNS (evite!):**

❌ "Oi, tudo bem? Preciso de camisetas..."  
✅ "Prezado Sr. Silva, Solicito orçamento para camisetas..."

❌ "Obg pela atenção!!! 😊"  
✅ "Agradeço antecipadamente."

**Prazo de entrega:** Final da aula

## ✍️ ATIVIDADE 3 — Análise de E-mails Suspeitos

**Tempo:** 30 minutos | **Formato:** ✋ Manual (no papel)

**Objetivo:** Treinar seu "radar" para detectar phishing e golpes.

**O que você vai fazer:**

Você vai receber 3 e-mails (o professor vai entregar impressos). Para cada um, você precisa:

1. **Identificar se é legítimo ou suspeito**
2. **Listar todos os "RED FLAGS" (sinais de alerta)**
3. **Escrever a ação que você tomaria**

**Formato da sua resposta (no papel):**

```
E-MAIL 1: [Assunto do e-mail]

É legítimo? ( ) SIM  ( ) NÃO

Sinais de alerta encontrados:
□ Endereço estranho
□ Urgência artificial
□ Pede para clicar link
□ Erros de português
□ Oferece algo suspeito
□ Outro: _________________________

Ação que eu tomaria:
_________________________________
_________________________________
```

**Exemplos de e-mails que você vai analisar:**

**E-mail A:**
```
De: seu.banco@seubanc0.com.br
Assunto: AÇÃO URGENTE: Conta bloqueada!

Prezado cliente, sua conta foi acessada. 
Clique para recuperar: http://seu.banco.fake.ru/login
```

**E-mail B:**
```
De: rh@empresa-mesmo.com.br
Assunto: Agenda de férias — Setembro/2026

Prezado João,

Segue em anexo o calendário atualizado de férias.
Qualquer dúvida, entre em contato.

Att,
Departamento RH
```

**E-mail C:**
```
De: suporte@amazom.com
Assunto: Seu pedido foi entregue!

CLIQUE AQUI para confirmar recebimento e ganhe R$ 100 em créditos!!!
Oferta válida por 1 hora apenas!
```

**Prazo de entrega:** Final da aula

## ✍️ ATIVIDADE 4 — Criador de Senhas Forte

**Tempo:** 30 minutos | **Formato:** ✋ Manual (no papel)

**Objetivo:** Criar uma senha forte usando a fórmula aprendida.

**O que você vai fazer:**

1. **Pegue uma folha**
2. **Escolha** uma palavra preferida (ex: "gato")
3. **Escolha** um número importante (ex: 15, seu dia de aniversário)
4. **Escolha** um símbolo (ex: @, #, $, !, &)
5. **Escolha** uma maiúscula aleatória (ex: K)
6. **Monte a senha** seguindo a ordem

**Formato da sua resposta:**

```
CRIADOR DE SENHAS FORTE

Minha palavra preferida: _______________
Meu número importante: _________________
Meu símbolo especial: __________________
Minha maiúscula: _______________________

MINHA SENHA: ___________________________

Ela é forte? (Conte os caracteres)
Total de caracteres: ___ (mínimo 12)

Tem maiúscula? ( ) SIM  ( ) NÃO
Tem minúscula? ( ) SIM  ( ) NÃO
Tem número? ( ) SIM  ( ) NÃO
Tem símbolo? ( ) SIM  ( ) NÃO

Força da minha senha:
( ) Fraca  ( ) Média  ( ) Forte  ( ) Muito forte
```

**Dicas:**

- Não use uma senha real que você usa em lugar nenhum!
- Quanto mais elementos misturados, mais forte
- Escreva por extenso como você formou (ajuda a guardar)

**Prazo de entrega:** Final da aula

## ✍️ ATIVIDADE 6 — Avaliação de Colegas

**Tempo:** 30 minutos | **Formato:** ✋ Manual (no papel)

**Objetivo:** Treinar o olhar crítico e construtivo para feedback.

**O que você vai fazer:**

Enquanto cada colega apresenta, você vai preencher uma ficha de avaliação.

**Formato (uma ficha por colega):**

```
FICHA DE AVALIAÇÃO — APRESENTAÇÃO DO COLEGA

Colega que apresentou: ____________________

COMO FOI A APRESENTAÇÃO?

1. Clareza (o quanto você entendeu):
   ( ) Muito claro  ( ) Claro  ( ) Confuso

2. Confiança (como ele/ela falou):
   ( ) Muito confiante  ( ) Normal  ( ) Tímido

3. Tempo (durou quanto deveria):
   ( ) Muito curto  ( ) Ideal  ( ) Muito longo

4. Estrutura (teve começo, meio, fim):
   ( ) Sim, muito bem  ( ) Mais ou menos  ( ) Não

5. PONTO FORTE (o que saiu bem):
   _____________________________________

6. PONTO A MELHORAR (o que poderia melhorar):
   _____________________________________

7. UMA MENSAGEM POSITIVA PARA O COLEGA:
   _____________________________________
   _____________________________________
```

**Prazo de entrega:** Ao final de todas as apresentações
