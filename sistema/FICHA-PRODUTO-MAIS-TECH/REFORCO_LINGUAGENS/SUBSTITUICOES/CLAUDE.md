## ⏱️ Cronograma Recomendado para Substituição

### Caso 1: Substituir 1 Encontro (2h)

**Opção A — Conteúdo Rápido:**
- Encontro isolado do Módulo 1, 2, 3, 4 ou 5
- Revisão rápida de um tópico já lecionado
- Atividade interativa de 2h

**Opção B — Aula de Reforço:**
- Usar um dos **Textos de Reforço** (TEXTO-REFORCO-MODELO-01 até 05)
- Tempo: 2h (leitura, compreensão, atividades)

### Caso 2: Substituir 4 Encontros (8h)

**Sugestão:**
1. **Encontro 1–2 (Módulo 1):** Tipos de texto e contexto — 4h
   - Apostila: pp. 83–100
   - Atividades: ATIVIDADE-EPISODIO-01 (disponível em REFORCO_LINGUAGENS/)

### Caso 3: Substituir 8 Encontros (16h) — Módulo Completo

**Sugestão:**
- **Módulo 1 completo (Encontros 1–7):** 15h
  - Dividir em 8 aulas de 2h cada
  - Usar apostila + Textos de Reforço + Atividades
  - Avaliação ao final com exercícios do CLAUDY.md

## ✅ Passo a Passo: Montar uma Aula de Substituição

### 1. Acessar o SGN e Identificar Aulas Faltantes

```
https://sgn.sesisenai.org.br/pages/diarioClasse/diario-classe.html?idDiario=XXXXX
```

- [ ] Login realizado
- [ ] Seção "Aulas/Avaliações" acessada
- [ ] Lista de aulas lecionadas copiada
- [ ] Aulas faltantes identificadas

### 2. Selecionar Encontros para Substituição

- [ ] Escolher 1, 2, 4 ou mais encontros da tabela acima
- [ ] Verificar se módulo está pronto (não há pré-requisitos não lecionados)
- [ ] Anotar CH total (horas)

### 3. Preparar Material

**Se substituir Encontro 1–2 (Módulo 1, 4h):**
- [ ] Abrir `Apostila_Reforco_Linguagens.md`, pp. 83–100
- [ ] Baixar/imprimir `ATIVIDADE-EPISODIO-01.pdf`
- [ ] Preparar slides com `Slides_Reforco_Linguagens.pptx`

**Se usar Texto de Reforço (2h):**
- [ ] Escolher `TEXTO-REFORCO-MODELO-0X.md` (apropriado ao módulo)
- [ ] Imprimir ou compartilhar digitalmente com alunos
- [ ] Preparar as atividades e gabarito

### 4. Lecionar a Aula de Substituição

- [ ] Iniciar com objetivos do encontro (apostila pp. XX)
- [ ] Ler/discutir conteúdo principal
- [ ] Realizar atividades práticas (30–45 min)
- [ ] Fazer síntese e feedback

### 5. Registrar no SGN

- [ ] Acessar SGN novamente
- [ ] Marcar encontro como "Lecionado"
- [ ] Informar data e conteúdo exato lecionado
- [ ] Lançar notas/presenças conforme necessário

## 🔴 Considerações Importantes

### Pré-requisitos de Módulos

⚠️ **ATENÇÃO:** Respeitar a sequência de módulos para que os alunos tenham base:

- **Módulo 1** → Leitura (fundamental)
- **Módulo 2** → Produção (depende de entender leitura)
- **Módulo 3** → Gramática (pode ser paralelo ou após Módulo 2)
- **Módulo 4** → Comunicação Oral (independente, mas recomenda Módulos 1–2)
- **Módulo 5** → Autonomia (pode ser ao final ou paralelo)

### Se Faltarem Muitos Encontros (>16h)

Opções:
1. **Fazer avaliação cumulativa** dos encontros não lecionados
2. **Condensar conteúdo** (usar textos de reforço, não aulas completas)
3. **Consultar coordenação** sobre possibilidade de extensão

## 🚀 Dicas para Aulas de Substituição Eficazes

1. **Comece sempre explicando o objetivo** do encontro
2. **Use exemplos práticos** conectados à realidade dos alunos
3. **Reserve tempo para atividades** (não só exposição)
4. **Faça revisão rápida** dos conceitos principais
5. **Deixe tempo para dúvidas** e feedback
6. **Atualize o SGN imediatamente** após a aula
