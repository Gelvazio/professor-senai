## 🎯 Tema da Aula

**Conceitos Fundamentais e Planejamento de Testes**

---

## 📚 Conteúdos Programáticos

### Conceitos Fundamentais (5.1-5.2)
- **Verificação:** Garantir que o produto foi desenvolvido corretamente (Did we build it right?)
- **Validação:** Garantir que o produto correto foi desenvolvido (Did we build the right thing?)

### Planejamento de Testes Client-Side (6.1-6.4)
- **Análise de Requisitos:** Leitura e compreensão de documento de requisitos
- **Plano de Testes:** Estrutura e organização de plano de testes
- **Suíte de Testes:** Agrupamento lógico de testes
- **Casos de Testes:** Especificação e cobertura de casos de teste

### Especificações Técnicas de Interface
- Compreender documentação de interface (wireframes, mockups)
- Entender requisitos de teste do projeto
- Reconhecer etapas de planejamento de testes

---

## 🎓 Capacidades a Serem Trabalhadas

Ao final da aula, o aluno deverá ser capaz de:

✅ Diferenciar verificação de validação  
✅ Compreender especificações técnicas de interface  
✅ Criar plano de testes estruturado e bem-organizado  
✅ Definir casos de teste com clareza e precisão  
✅ Documentar requisitos de teste apropriadamente  

---

## 🏫 Estratégias de Ensino

### Metodologia
- **Apresentação de Conceitos:** Diagramas visuais comparativos (V&V)
- **Análise de Documento Real:** Exemplo de documento de requisitos verdadeiro
- **Exercício Prático:** Criar plano de testes para componente web real
- **Discussão:** "Como especificações afetam o plano de testes?"

### Timeline da Aula (4 horas)

1. **Revisão Aula Anterior (15 min):** Recap de tipos de testes
2. **Conceitos V&V (45 min):** Verificação vs. Validação com exemplos
3. **Planejamento Prático (90 min):** Documento de requisitos → Plano de testes
4. **Exercício Individual (45 min):** Aluno cria seu próprio plano

## 📋 Instrumentos de Avaliação

- **Exercício Prático:** Plano de testes para interface fornecida

- **Checklist de Completude:** Verificar se plano tem todos os elementos obrigatórios

---

## 🎬 Atividades Propostas

### Atividade 1: Análise de Requisitos (30 min)
Leitura conjunta de documento de requisitos; identificar requisitos de teste.

### Atividade 2: Criação de Plano (90 min)
Aluno cria plano de testes detalhado com casos de teste específicos.

### Atividade 3: Peer Review (30 min)
Duplas trocam planos e comentam sobre clareza e cobertura.
