## ✅ Critérios de Aprovação

### Avaliação Prática
- ✓ Testes unitários: ≥5 casos cobrindo happy path e edge cases
- ✓ Testes de integração: validação de comportamento completo
- ✓ Testes E2E: ≥3 cenários de fluxo de usuário
- ✓ Cobertura de código: ≥70%
- ✓ Código limpo: sem duplicação, bem-estruturado
- ✓ Execução em CI/CD: funcional

### Avaliação Teórica
- ✓ Mínimo de 60% de acerto (24/40 questões)
- ✓ Compreensão de todos os blocos temáticos

### Nota Final
```
Nota Final = (Contínua × 0,60) + (Prática × 0,25) + (Teórica × 0,15)
Aprovação: ≥ 6,0
```
