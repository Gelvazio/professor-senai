::HC10::Qual é a diferença entre HD e SSD?{

~HD é mais rápido e SSD armazena dados temporariamente
~Ambos têm a mesma velocidade, mas o SSD é maior
~HD armazena dados em nuvem, SSD armazena localmente
}

::HC11::Qual é a sequência correta do ciclo básico de funcionamento de um computador?{

~Processamento → Entrada → Saída → Armazenamento
~Armazenamento → Saída → Entrada → Processamento
}

::HC12::O que diferencia hardware de software?{
=Hardware é a parte física (tudo que se pode tocar); software é a parte lógica (programas e instruções)
~Hardware são os programas e software são os componentes físicos
~Hardware é o sistema operacional e software são os periféricos
~Hardware e software são termos sinônimos para componentes do computador
}
