## 🎯 Competência Geral do Curso

**Produzir interfaces e desenvolver sistemas para internet, de acordo com metodologia e padrões de qualidade, usabilidade, interatividade, robustez, acessibilidade e segurança da informação.**

### Funções Principais:

1. **Produzir Interfaces para Internet** - Projetar, codificar e testar interfaces web de acordo com padrões de usabilidade, interatividade e acessibilidade.

2. **Desenvolver Sistemas para Internet** - Implementar sistemas completos com banco de dados, APIs e integração entre camadas, seguindo metodologias ágeis e boas práticas.
