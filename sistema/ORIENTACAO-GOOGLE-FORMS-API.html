Visão Geral — Dois caminhos possíveis

Existem duas formas principais de trabalhar com Google Forms programaticamente:

AbordagemO que fazQuando usar
Google Apps Script (FormApp) Cria, edita e publica formulários diretamente na conta Google, sem precisar de API key externa Criação automática de formulários — já usado nos scripts .gs
Google Forms REST API + Google Sheets API Lê respostas de formulários existentes via HTTP (OAuth 2.0), integra com outros sistemas Conectar respostas ao Supabase ou exportar dados para planilhas externas
✅ Os scripts .gs desta pasta já usam a abordagem 1 (FormApp). Para integrar respostas ao sistema do SENAI, a abordagem 2 é o próximo passo.

Cada arquivo .gs cria automaticamente um Google Form com questões de múltipla escolha, discursivas e seções. Siga os passos:

1

Acesse script.google.com

Faça login com a conta Google SENAI (ou pessoal) e clique em Novo projeto.

2

Cole o código do script

Referência Rápida — FormApp (Google Apps Script)

O objeto principal é FormApp. Todas as operações partem dele:

Apps Script 
// Criar formulário
var form = FormApp.create('Título do Formulário');

// Configurações gerais
form.setDescription('Descrição...');
form.setCollectEmail(true);          // coleta e-mail do respondente
form.setLimitOneResponsePerUser(true); // 1 resposta por conta
form.setProgressBar(true);           // barra de progresso

// Seção (cabeçalho)
form.addSectionHeaderItem()
  .setTitle('Parte 1 — Identificação')
  .setHelpText('Preencha seus dados.');

// Pergunta de múltipla escolha
var q1 = form.addMultipleChoiceItem();
q1.setTitle('1. Qual é a extensão do Word?')
  .setChoices([
    q1.createChoice('.txt'),
    q1.createChoice('.docx', true), // true = resposta correta
    q1.createChoice('.xlsx')
  ])
  .setRequired(true);

// Pergunta discursiva (parágrafo)
form.addParagraphTextItem()
  .setTitle('Descreva o que você aprendeu...')
  .setRequired(false);

// Pergunta de texto curto
form.addTextItem()
  .setTitle('Nome completo')
  .setRequired(true);

// Imprimir links nos logs
Logger.log('🔗 Preencher: ' + form.getPublishedUrl());
Logger.log('✏️ Editar: '    + form.getEditUrl());
MétodoTipo de item criado
addMultipleChoiceItem()Múltipla escolha (radio)
addCheckboxItem()Caixas de seleção (checkbox)
addTextItem()Resposta curta
addParagraphTextItem()Resposta longa / dissertativa
addSectionHeaderItem()Cabeçalho de seção
addListItem()Lista suspensa (dropdown)
addScaleItem()Escala numérica (ex: 1 a 5)
addDateItem()Seletor de data
addImageItem()Inserir imagem

Ler Respostas de um Formulário Existente

Após criar o formulário, as respostas ficam armazenadas no próprio Google Forms. Há duas maneiras de acessá-las programaticamente:

Opção A — Pelo próprio Apps Script (sem OAuth externo)

Apps Script 
function lerRespostas() {
  // Substitua pelo ID do formulário (da URL)
  var form = FormApp.openById('1BxiMVs0XRA...');
  var respostas = form.getResponses();

  respostas.forEach(function(r) {
    Logger.log('E-mail: ' + r.getRespondentEmail());
    Logger.log('Data:   ' + r.getTimestamp());

    var itens = r.getItemResponses();
    itens.forEach(function(item) {
      Logger.log(item.getItem().getTitle() + ' → ' + item.getResponse());
    });
  });
}

Opção B — Via Google Sheets vinculado (mais fácil para exportar)

Dentro do Google Forms, clique em Respostas → ícone do Sheets para criar uma planilha vinculada. Todas as respostas aparecem lá automaticamente. Em seguida, leia a planilha pelo Apps Script:

Apps Script 
function lerDaPlanilha() {
  var ss = SpreadsheetApp.openById('ID_DA_PLANILHA');
  var aba = ss.getActiveSheet();
  var dados = aba.getDataRange().getValues();

  // Primeira linha = cabeçalhos, restante = respostas
  var cabecalhos = dados[0];
  for (var i = 1; i < dados.length; i++) {
    var linha = dados[i];
    Logger.log('Aluno: ' + linha[1] + ' | Nota: ' + linha[3]);
  }
}

Integrar Respostas ao Sistema SENAI (Supabase)

Para enviar respostas do Google Forms diretamente ao banco de dados Supabase, use UrlFetchApp dentro do Apps Script — sem precisar de outro servidor.

ℹ️ Configuração necessária: crie um trigger onFormSubmit no Apps Script para executar a função automaticamente a cada nova resposta.
Apps Script 
// Configurações do Supabase
var SUPABASE_URL = 'https://jwasbzdbkbryncpvfujc.supabase.co';
var SUPABASE_KEY = 'sua_anon_key_aqui';

// Função chamada a cada nova resposta (conecte ao trigger onFormSubmit)
function onFormSubmit(e) {
  var respostas = e.response.getItemResponses();
  var payload = {
    email:       e.response.getRespondentEmail(),
    data_hora:   new Date().toISOString(),
    nome_aluno:  respostas[0].getResponse(),
    nota:        calcularNota(respostas)
  };

  UrlFetchApp.fetch(SUPABASE_URL + '/rest/v1/respostas_forms', {
    method: 'POST',
    headers: {
      'apikey':        SUPABASE_KEY,
      'Authorization': 'Bearer ' + SUPABASE_KEY,
      'Content-Type':  'application/json',
      'Prefer':        'return=minimal'
    },
    payload: JSON.stringify(payload)
  });
}

function calcularNota(respostas) {
  // Implemente sua lógica de correção aqui
  return 0;
}

// ── Criar o trigger onFormSubmit ──
function criarTrigger() {
  var form = FormApp.getActiveForm();
  ScriptApp.newTrigger('onFormSubmit')
    .forForm(form)
    .onFormSubmit()
    .create();
  Logger.log('Trigger criado!');
}
⚠️ Segurança: nunca publique o arquivo .gs com a service_role key do Supabase. Use apenas a anon key, que tem permissões limitadas conforme as Row Level Security policies configuradas.

Como configurar o trigger manualmente

  1. No Apps Script, clique no ícone de relógio (Triggers) no menu lateral esquerdo
  2. Clique em + Adicionar trigger (canto inferior direito)
  3. Função: onFormSubmit | Origem do evento: No envio do formulário
  4. Clique em Salvar e autorize as permissões

Gabarito Automático com isCorrectAnswer()

O Google Forms suporta correção automática de questões de múltipla escolha. O segundo parâmetro de createChoice() marca a resposta correta:

Apps Script 
var q = form.addMultipleChoiceItem();
q.setTitle('Extensão padrão do Word?')
 .setChoices([
   q.createChoice('.txt', false),
   q.createChoice('.docx', true),  // ← resposta correta
   q.createChoice('.xlsx', false)
 ])
 .setPoints(1)         // pontuação desta questão
 .setRequired(true);

// Habilitar correção automática no formulário
form.setIsQuiz(true);
form.setShowLinkToRespondAgain(false);

// Exibir nota após envio (opcional)
form.setPublishingSummary(true);

Com setIsQuiz(true), o Google Forms corrige automaticamente e mostra a nota ao aluno após o envio.
