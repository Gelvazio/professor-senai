| CONTEXTUALIZAÇÃO |
| --- |
| Uma empresa de tecnologia especializada no desenvolvimento de soluções sob medida para diferentes segmentos da indústria está em fase de expansão. O setor de engenharia de software foi encarregado de desenvolver novos sistemas para atender demandas de clientes que buscam automatizar processos e integrar dados operacionais.
Entre os projetos em andamento, há solicitações de desenvolvimento para sistemas como:
Delivery de comida
Aplicativo de transporte
Loja de departamentos
Streaming de vídeo
Gerenciamento de estoque
Hospital
Escola
Empresa de Recursos Humanos (RH)
Oficina mecânica
Fábrica de chocolate
Academia
Imobiliária
Hotel ou pousada
Laboratório de análises clinicas
Agencia de viagens 
Salão de beleza ou barbearia 
Lavanderia 
Fintech de Crédito e Empréstimos
Gestão de Condomínios
Postos de Combustível e Conveniência
Corretora de Seguros
Cada projeto possui particularidades, mas todos exigem a construção de um sistema funcional com modelagem de requisitos, estrutura de banco de dados e interface de aplicação. |
| DESAFIO |
| --- |
| Cada Técnico em Desenvolvimento de Sistemas foi contratado para desenvolver um dos projetos propostos à uma aplicação funcional que atenda às necessidades do cliente, assegurando qualidade, integridade, usabilidade e segurança das informações tratadas. |
