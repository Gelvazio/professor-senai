### Capacidades do Itinerário

#### Capacidades Técnicas:

- **CT1** - Identificar conceitos, tipos, características e armazenamento do banco de dados do sistema computacional.
- **CT2** - Distinguir arquitetura de banco de dados de acordo com aplicação.
- **CT3** - Identificar métodos de normalização de banco de dados.
- **CT4** - Identificar sistemas de gerenciamento de banco de dados.
- **CT5** - Instalar sistema de gerenciamento de banco de dados (SGBD) conforme especificações para funcionamento do banco de dados.
- **CT6** - Identificar características de modelagem de dados para organização e estrutura de armazenamento de dados.
- **CT7** - Aplicar técnicas para modelagem do banco de dados, de acordo com sua estrutura.
- **CT8** - Aplicar procedimentos de segurança e backup no SGBD.
- **CT9** - Identificar linguagem de banco de dados relacionais e não-relacionais para consulta, manipulação, controle e definição.
- **CT10** - Identificar ferramentas de manipulação de banco de dados.
- **CT11** - Aplicar linguagem para consulta, manipulação e controle do banco de dados.
- **CT12** - Empregar comentários para a documentação do código fonte.

#### Capacidades Socioemocionais:

- **CS1** - Apresentar comportamento ético no desenvolvimento das atividades sob a sua responsabilidade.
- **CS2** - Tomar decisões no planejamento e na resolução de problemas relacionados às atividades sob sua responsabilidade.
- **CS3** - Demonstrar profissionalismo no exercício de suas responsabilidades e sintonia com as diretrizes institucionais estabelecidas.

## CONTEXTUALIZAÇÃO

Uma empresa de tecnologia especializada no desenvolvimento de soluções sob medida para diferentes segmentos da indústria está em fase de expansão. O setor de engenharia de software foi encarregado de desenvolver novos sistemas para atender demandas de clientes que buscam automatizar processos e integrar dados operacionais.

Entre os projetos em andamento, há solicitações de desenvolvimento para sistemas como:

- Delivery de comida
- Aplicativo de transporte
- Loja de departamentos
- Streaming de vídeo
- Gerenciamento de estoque
- Hospital
- Escola
- Empresa de Recursos Humanos (RH)
- Oficina mecânica
- Fábrica de chocolate
- Academia
- Imobiliária
- Hotel ou pousada
- Laboratório de análises clínicas
- Agência de viagens
- Salão de beleza ou barbearia
- Lavanderia
- Fintech de Crédito e Empréstimos
- Gestão de Condomínios
- Postos de Combustível e Conveniência
- Corretora de Seguros

Cada projeto possui particularidades, mas todos exigem a construção de um sistema funcional com modelagem de requisitos, estrutura de banco de dados e interface de aplicação.

---

## DESAFIO

Cada Técnico em Desenvolvimento de Sistemas foi contratado para desenvolver um dos projetos propostos, transformando-o em uma aplicação funcional que atenda às necessidades do cliente, assegurando qualidade, integridade, usabilidade e segurança das informações tratadas.
