Introdução
parágrafo — justificado · recuo de primeira linha 1,25 cm · espaçamento 1,5

O Google Docs é um editor de textos online que faz parte do Google Workspace, pacote de ferramentas de produtividade desenvolvido pela Google. Diferente de editores simples, como o Bloco de Notas, o Google Docs permite realizar formatações avançadas, inserir tabelas, imagens, listas e gráficos, tudo diretamente pelo navegador de internet, sem necessidade de instalação de programas adicionais.

Uma das maiores vantagens do Google Docs é o salvamento automático no Google Drive. O documento é atualizado continuamente, eliminando o risco de perda de dados por falta de salvar o arquivo. Além disso, é possível colaborar em tempo real: vários usuários editam o mesmo documento ao mesmo tempo, de qualquer lugar, desde que tenham acesso à internet. Essa funcionalidade é muito utilizada em ambientes de trabalho modernos, onde o trabalho em equipe e a comunicação eficiente são fundamentais para a produtividade.

Formatação e Normas ABNT
parágrafo — justificado · recuo de primeira linha 1,25 cm · espaçamento 1,5

Para produzir documentos profissionais no ambiente de trabalho, é necessário seguir as normas da ABNT. No Google Docs, as configurações de página são acessadas em Arquivo → Configurar página. As margens exigidas são: superior 3 cm, inferior 2 cm, esquerda 3 cm e direita 2 cm. O espaçamento entre linhas deve ser de 1,5 e o recuo de primeira linha de cada parágrafo deve ser de 1,25 cm. Para aplicar formatações rapidamente, use os atalhos de teclado: Ctrl+B para negrito, Ctrl+I para itálico, Ctrl+J para justificado e Ctrl+\ para remover toda a formatação do texto selecionado.
