1.2 As 5 Gerações dos Computadores

1.3 Como Funciona um Computador
Todo computador opera segundo um ciclo fundamental de quatro etapas:
• Entrada: o usuário insere dados por teclado, mouse, microfone, câmera ou sensores
• Processamento: a CPU (processador) executa as instruções — é o "cérebro" do computador
• Armazenamento: memória RAM (temporária) e HD/SSD (permanente) guardam os dados
• Saída: o resultado é exibido no monitor, impresso ou enviado para outros dispositivos
Resumo: Entrada → Processamento → Armazenamento → Saída — ciclo básico de qualquer computador.
1.4 Software — Tipos e Características
Software é o conjunto de programas e instruções que dizem ao hardware o que fazer. Divide-se em:
• Software de Sistema: sistema operacional (Windows, Linux, Chrome OS), drivers e firmware
• Software Aplicativo: programas para tarefas específicas — Google Docs, Excel, Chrome
• Software Embarcado: instalado em equipamentos industriais — CLPs, robôs, sensores
• Software Livre (Open Source): código aberto, gratuito — Linux, LibreOffice
1.5 O Chromebook e o Chrome OS
O Chromebook é um notebook que utiliza o Chrome OS, sistema operacional criado pelo Google. Suas principais características são:
• Inicializa em segundos e foca no uso online, com aplicativos rodando no navegador
• Arquivos salvos automaticamente no Google Drive — sem risco de perda por falta de "salvar"
• Naturalmente seguro: baixo risco de vírus e atualizações automáticas
• Ideal para o ambiente educacional e colaborativo

Capítulo 2 — Comunicação em Equipes de Trabalho
2.1 O que é Comunicação?
Comunicação é o processo de transmitir e receber informações, ideias ou sentimentos entre pessoas. Para ser eficaz, a mensagem deve ser clara, completa e compreendida pelo receptor.
Tipos de comunicação:
• Oral: conversas, reuniões, apresentações, telefonemas
• Escrita: e-mails, relatórios, atas, mensagens, chats
• Não-verbal: gestos, postura, expressão facial, tom de voz
• Visual: gráficos, infográficos, sinalizações, símbolos
Estudos mostram que 70% dos problemas organizacionais têm origem em falhas de comunicação. Profissional que se comunica bem tem mais visibilidade e oportunidades de crescimento.

2.3 Trabalho em Equipe
Equipe é diferente de grupo: na equipe, existe interdependência — o resultado de um depende do trabalho do outro. Na indústria, a maioria das atividades exige trabalho em equipe.
Características de uma equipe de alto desempenho:
• Objetivo comum claro e compartilhado por todos os membros
• Papéis e responsabilidades bem definidos — cada um sabe o que faz
• Comunicação aberta, frequente e respeitosa
• Confiança mútua e comprometimento com o resultado coletivo
• Feedback contínuo para identificar e corrigir problemas

2.4 Busca de Consenso
Consenso é quando todos os membros concordam com uma decisão e se comprometem a executá-la — mesmo que não seja a preferência individual de todos. Consenso não é unanimidade.
Técnicas para facilitar o consenso:
• Brainstorming: todos lançam ideias livremente, sem julgamento
• Votação ponderada: cada membro distribui pontos entre as opções
• Rodada de fala: cada membro tem tempo igual para se expressar
• Critérios objetivos: decidir com base em dados, custos e prazos
• Ata de decisão: registrar o que foi decidido, responsáveis e prazos
2.5 Gestão de Conflitos
Conflito é o choque entre interesses, opiniões ou necessidades diferentes. É inevitável em qualquer equipe — o problema não é o conflito em si, mas como ele é gerenciado.
Tipos de conflito:
• Conflito de tarefa: discordância sobre o trabalho a ser feito (pode ser saudável)
• Conflito de processo: divergência sobre como realizar o trabalho
• Conflito de relacionamento: desentendimentos pessoais (sempre prejudicial)

Regra de ouro: ataque o problema, não a pessoa. Discuta fatos, não caráter.
2.6 Comunicação Assertiva
Assertividade é expressar opiniões, necessidades e sentimentos de forma direta, clara e respeitosa — sem agressividade e sem passividade.
2.7 Níveis de Fala
A linguagem pode ser utilizada em diferentes níveis, e a escolha correta depende do contexto e do receptor:
• Linguagem culta: variante formal, segue as normas gramaticais — usada em documentos, e-mails e reuniões formais
• Linguagem técnica: vocabulário especializado de uma área profissional — precisa e objetiva entre especialistas
• Jargão: variante informal da linguagem técnica — adequado apenas entre profissionais do mesmo campo
• Linguagem informal: conversas cotidianas — inadequada para o ambiente profissional formal
Regra de ouro: com leigos (clientes, familiares, outras áreas), traduza o jargão para linguagem acessível.

Capítulo 3 — Segurança da Informação
3.1 O que é Segurança da Informação?
Segurança da Informação é o conjunto de práticas, processos e tecnologias para proteger dados contra acessos não autorizados, perdas ou modificações indevidas.
As informações precisam ser protegidas em três estados:
• Em repouso: arquivos guardados no HD, SSD ou nuvem
• Em trânsito: dados sendo transmitidos pela internet ou rede
• Em uso: informações abertas e sendo processadas pelo sistema

3.3 LGPD — Lei Geral de Proteção de Dados
A Lei nº 13.709/2018 regula o tratamento de dados pessoais por empresas e organizações no Brasil, em vigor desde setembro de 2020.
Dados pessoais incluem: nome, CPF, e-mail, telefone, localização, foto, dados de saúde, entre outros.
Direitos do titular dos dados:
• Saber quais dados a empresa possui sobre você
• Solicitar a correção de dados incorretos
• Pedir a exclusão dos seus dados
• Revogar o consentimento a qualquer momento
Empresas que descumprirem a LGPD podem ser multadas em até 2% do faturamento anual ou R$ 50 milhões por infração.
3.4 Principais Golpes na Internet
3.5 Criação de Senhas Seguras
A senha é o principal mecanismo de proteção de contas. Uma senha forte combina letras maiúsculas e minúsculas + números + símbolos, com no mínimo 12 caracteres.
Erros mais comuns a evitar:
• Usar senhas óbvias: 123456, senha, nome + ano de nascimento
• Reutilizar a mesma senha em vários sites ou sistemas
• Compartilhar senhas com colegas de trabalho

Método da frase-senha:
Pense em uma frase: "Meu gato tem 3 patas!" → Use iniciais e substitua: Mgt3P@t4s! — fácil de lembrar, difícil de adivinhar.

Autenticação em Dois Fatores (2FA): adiciona uma segunda camada de verificação além da senha. Mesmo que sua senha vaze, a conta permanece protegida. Use sempre que disponível.
3.6 Backup — Regra 3-2-1
Backup é a cópia de segurança dos dados, fundamental para garantir a disponibilidade das informações.
A Regra 3-2-1 é o padrão recomendado de backup:
• 3 cópias dos dados
• 2 tipos diferentes de mídia (ex: HD externo e nuvem)
• 1 cópia em local separado (offsite)

A Internet é uma rede mundial de computadores interligados por cabos, fibras ópticas e sinais de rádio. Criada nos anos 1960 pelo governo americano (ARPANET) como rede militar, foi aberta ao público nos anos 1990 e mudou o mundo para sempre. Hoje conecta mais de 5 bilhões de pessoas.

5.2 Periféricos
Periféricos são dispositivos externos conectados ao computador para ampliar suas capacidades:
5.3 Sistema Operacional
O Sistema Operacional (SO) é o software que gerencia o hardware e permite que outros programas funcionem. É a base de todo o computador.
5.4 Organização de Arquivos
A organização de arquivos é fundamental para produtividade. O sistema operacional utiliza uma estrutura hierárquica de pastas (diretórios):
• Pasta raiz: nível mais alto do sistema de arquivos (C:\ no Windows, / no Linux)
• Pastas: organizam os arquivos por tema, projeto ou tipo
• Subpastas: pastas dentro de pastas — permitem hierarquia detalhada
• Arquivos: documentos, imagens, vídeos, programas — identificados pela extensão (.docx, .xlsx, .pdf)

Boas práticas de organização:
• Crie pastas com nomes descritivos e sem caracteres especiais
• Use datas no formato AAAA-MM-DD para facilitar a ordenação
• Mantenha uma pasta de trabalho e outra de arquivos pessoais separadas
• Faça backup regularmente das pastas importantes
5.5 Compactação de Arquivos
A compactação reduz o tamanho de arquivos para facilitar o armazenamento e o compartilhamento. Os formatos mais comuns são:
• .zip: padrão universal, compatível com todos os sistemas operacionais
• .rar: maior taxa de compressão, requer software específico (WinRAR)
• .7z: alta compressão, gratuito e de código aberto

6.1 O que é o Google Docs?
O Google Docs é um editor de textos online, parte do Google Workspace. Funciona diretamente no navegador, salva automaticamente no Google Drive e permite edição simultânea com outros usuários em tempo real.

6.2 Formatação de Texto
A formatação é essencial para tornar um documento legível e profissional:
• Fonte: tipo, tamanho e cor do texto — use fontes legíveis (Arial, Calibri, Times New Roman)
• Negrito, itálico, sublinhado: ênfases — use com moderação
• Alinhamento: esquerda (padrão), centralizado, direita, justificado
• Espaçamento entre linhas: 1.0, 1.5 ou 2.0 — documentos formais usam 1.5 ou 2.0
• Recuo de parágrafo: 1,25 cm (padrão ABNT) — indica início de novo parágrafo
• Marcadores e numeradores: para listas de itens ou passos ordenados
6.3 Configuração de Página
Configurações básicas de página para documentos formais:
• Margens: superior e inferior 2,5 cm; esquerda 3 cm; direita 2 cm (padrão ABNT)
• Tamanho de página: A4 (21 x 29,7 cm) — padrão brasileiro
• Orientação: retrato (vertical) ou paisagem (horizontal)
• Cabeçalho e rodapé: informações repetidas em todas as páginas (título, número de página)
• Numeração de páginas: inserida pelo menu Inserir → Números de página
6.4 Recursos Avançados
Recursos adicionais que tornam o documento mais completo:
• Tabelas: organizam dados em linhas e colunas — Inserir → Tabela
• Imagens: Inserir → Imagem → do Drive ou do computador
• Sumário automático: usa os títulos (Título 1, Título 2) para gerar índice automaticamente
• Comentários: permite revisar e sugerir alterações sem modificar o texto original
• Controle de versões: histórico completo de quem alterou o quê e quando
• Verificação ortográfica: Ferramentas → Verificar ortografia e gramática
6.5 Impressão e Exportação
Para imprimir ou exportar o documento:
• Imprimir: Arquivo → Imprimir (ou Ctrl+P) — configure o número de cópias e as páginas
• Exportar como PDF: Arquivo → Fazer download → Documento PDF
• Exportar como Word: Arquivo → Fazer download → Microsoft Word (.docx)
• Publicar na web: Arquivo → Compartilhar → Publicar na web (gera um link público)

Capítulo 7 — Google Sheets: Planilhas Eletrônicas
7.1 O que é o Google Sheets?
O Google Sheets é o aplicativo de planilhas eletrônicas do Google Workspace. Surgiu em 2006 como alternativa ao Microsoft Excel. Funciona diretamente no navegador, salva automaticamente no Google Drive e permite colaboração em tempo real com até 100 usuários simultâneos.
7.2 Estrutura da Planilha
A planilha é formada por uma grade de linhas e colunas:
• Linhas: identificadas por números (1, 2, 3...)
• Colunas: identificadas por letras (A, B, C...)
• Célula: interseção de uma linha e uma coluna — identificada por letra+número (ex: B3, D15)
• Intervalo: grupo de células — indicado por dois pontos (ex: A1:D10)
• Aba (planilha): cada arquivo pode ter várias abas — clique no "+" para adicionar

7.4 Formatação de Células
A formatação torna a planilha mais legível e profissional:

• Alinhamento: centralizar cabeçalhos, alinhar números à direita
• Cor de preenchimento: destaca células ou linhas importantes
• Bordas: delimitam áreas da planilha para facilitar a leitura
• Congelar linhas/colunas: mantém cabeçalhos visíveis ao rolar a planilha — Exibir → Congelar
7.5 Gráficos e Visualizações
Gráficos transformam dados numéricos em representações visuais:

Capítulo 8 — Google Slides: Editor de Apresentações
8.1 O que é o Google Slides?
O Google Slides é o aplicativo de criação de apresentações do Google Workspace. Lançado em 2007, funciona 100% no navegador Chrome, salva automaticamente no Drive e permite edição colaborativa em tempo real. É compatível com o formato .pptx do Microsoft PowerPoint.
8.2 Estrutura de uma Apresentação
Uma apresentação é composta por slides — telas individuais com conteúdo visual. Cada slide deve ter:
• Um título claro que identifica o tema do slide
• Conteúdo objetivo — evite textos longos; use tópicos e palavras-chave
• Imagens, ícones ou gráficos que complementam o conteúdo
• Design consistente — mesma paleta de cores e fontes em todos os slides
8.3 Boas Práticas de Apresentação
8.4 Recursos Disponíveis
O Google Slides oferece diversos recursos para criar apresentações impactantes:
• Temas: conjuntos de cores, fontes e layouts pré-definidos — use para consistência visual
• Layouts: modelos para organizar elementos no slide (título, conteúdo, imagem, etc.)
• Transições: animações entre slides — use com moderação
• Animações de objetos: elementos que aparecem em ordem durante a apresentação
• Inserir vídeo: do YouTube ou do Drive — enriquece a apresentação sem precisar abrir outra aba
• Apresentar: botão no canto superior direito — use o modo de apresentação com apontador laser
• Exportar: como PDF ou .pptx para compatibilidade com PowerPoint

Capítulo 9 — Textos Técnicos e Comunicação Profissional
9.1 O que são Textos Técnicos?
Textos técnicos são documentos formais e padronizados usados no ambiente profissional para registrar, comunicar e organizar informações. Cada tipo tem estrutura própria, finalidade específica e linguagem adequada ao contexto.
São fundamentais para garantir rastreabilidade, transparência e comunicação eficaz nas organizações. Saber identificar e produzir esses textos é uma habilidade básica exigida no mercado de trabalho.
9.2 Relatório
Documento que descreve atividades, resultados ou análises realizadas em um período ou projeto.
Finalidade: informar, registrar e subsidiar decisões gerenciais.
Estrutura básica:
• Identificação: título, data, autor/responsável
• Introdução: objetivo e contexto do relatório
• Desenvolvimento: dados, fatos, análises e tabelas
• Conclusão: resumo dos resultados e recomendações
Exemplo: "No mês de julho, a linha A registrou eficiência de 98%, com três eventos de parada não programada totalizando 4,5 horas. Recomenda-se revisão preventiva do compressor C-07."
9.3 Ata de Reunião
Documento que registra formalmente o que aconteceu em uma reunião: quem participou, o que foi discutido e o que foi decidido.
Finalidade: registrar decisões, atribuir responsabilidades e servir de prova do que foi acordado.
Estrutura básica:
• Data, hora, local e lista de participantes
• Pauta: assuntos tratados na reunião
• Deliberações e decisões tomadas
• Responsáveis e prazos definidos para cada ação
• Encerramento e assinaturas
Exemplo: "Em reunião realizada em 04/08/2026, às 14h, na sala de treinamento, ficou decidido que o setor de manutenção realizará a troca dos filtros até 07/08/2026, sendo o Sr. João responsável pela execução."
9.4 Memorando
Documento de comunicação interna entre setores ou colaboradores de uma mesma organização.
Finalidade: solicitar, informar, encaminhar ou comunicar algo de forma rápida e registrada.
Estrutura básica:
• PARA: destinatário e setor
• DE: remetente e setor
• DATA e N.º: data de emissão e número de protocolo
• ASSUNTO: título curto e objetivo
• Corpo da mensagem: linguagem formal, direta e objetiva
• Assinatura do remetente
Exemplo — PARA: Almoxarifado | DE: Produção | DATA: 04/08/2026 | ASSUNTO: Solicitação de EPI | Solicitamos o fornecimento de 10 pares de luvas de nitrila (tamanho M) para reposição do estoque do setor.
9.5 Resumo
Texto que sintetiza as ideias principais de um documento mais extenso, mantendo o sentido original sem incluir opinião própria.
Finalidade: facilitar a compreensão rápida de um conteúdo, sem ler o documento completo.
Características essenciais:
• Fidelidade ao original — não inclui opinião ou interpretação pessoal
• Brevidade — apenas o essencial
• Clareza — linguagem acessível e bem estruturada
• Coerência — mantém a lógica do texto original

Capítulo 10 — Ferramentas Microsoft 365
10.1 O que é o Microsoft 365?
O Microsoft 365 é o pacote de aplicativos de produtividade criado pela Microsoft — o mais usado no ambiente corporativo mundial. Está disponível em duas versões:
• Versão instalada (paga): Word, Excel, PowerPoint, Outlook e mais — exige compra de licença ou assinatura

Editor de textos mais utilizado no mundo corporativo. Equivalente ao Google Docs.
Diferenciais em relação ao Google Docs:
• Ferramentas avançadas de formatação e estilos

• Suporte completo às normas ABNT para trabalhos acadêmicos

10.3 Microsoft Excel
Planilha eletrônica mais usada no mundo, referência em análise de dados. Equivalente ao Google Sheets.
Recursos exclusivos ou avançados:
• Tabelas dinâmicas: análise interativa de grandes volumes de dados
• Power Query: importação e transformação automática de dados de diversas fontes
• Macros e VBA: automatização de tarefas repetitivas com programação
• Mais de 400 funções disponíveis — da estatística ao financeiro
• Modo offline completo — ideal quando não há conexão com internet
10.4 Microsoft PowerPoint
Editor de apresentações de slides, líder de mercado no ambiente corporativo. Equivalente ao Google Slides.
Recursos avançados:
• Animações e transições com maior variedade e controle

Principais recursos:
• E-mail com regras automáticas de organização e filtros
• Calendário integrado com agendamento de reuniões e convites
• Agenda de contatos sincronizada com Teams e outros apps Microsoft
• Integração com Microsoft Teams para videochamadas diretamente do e-mail
10.6 OneDrive — Armazenamento em Nuvem

| Golpe | Como funciona | Como se proteger |
| --- | --- | --- |
| Phishing | E-mail/mensagem falsa que redireciona para site fraudulento para roubar dados | Verifique o remetente; bancos nunca pedem senha por e-mail |
| Ransomware | Malware que criptografa os arquivos e exige resgate em criptomoeda | Backup regular, sistemas atualizados, não abrir anexos suspeitos |
| Engenharia social | Manipulação psicológica para obter informações confidenciais | Desconfie de urgência excessiva; verifique a identidade do solicitante |
| Clonagem WhatsApp | Golpista pede o código de verificação SMS por ligação | Nunca compartilhe o código de 6 dígitos de nenhum app |
| Vishing | Phishing por telefone — golpista se passa por banco ou autoridade | Desligue e ligue de volta pelo número oficial da instituição |
| Tipo | Descrição | Como age |
| --- | --- | --- |
| Vírus | Programa que se anexa a arquivos legítimos | Se espalha quando o arquivo infectado é aberto |
| Ransomware | Sequestra e criptografa arquivos | Exige pagamento para liberar os dados |
| Trojan (Cavalo de Tróia) | Parece legítimo mas é malicioso | Abre porta para acesso remoto do hacker |
| Spyware | Espiona atividades do usuário | Captura senhas, histórico e dados bancários |
| Adware | Exibe anúncios indesejados | Redireciona o navegador, coleta dados de navegação |
| Worm | Replica-se automaticamente pela rede | Consome recursos e propaga outros malwares |
