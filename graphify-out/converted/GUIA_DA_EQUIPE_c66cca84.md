# Como organizar e proteger o computador do setor

## 1. Problema e solução proposta

O computador do setor está desorganizado porque os arquivos estão espalhados, não existe uma rotina de backup e alguns funcionários recebem mensagens suspeitas. Além disso, a equipe não conhece bem os equipamentos e programas utilizados. Para solucionar o problema, propomos organizar os arquivos em pastas, realizar backups semanais, manter os programas de segurança atualizados e orientar os funcionários sobre senhas, navegação segura e golpes. Dessa forma, o setor poderá trabalhar com mais organização e reduzir os riscos de perda ou roubo de informações.

## 2. Hardware e software

Hardware é a parte física do computador, ou seja, os equipamentos que podemos tocar. Dois exemplos são a CPU (processador) e o SSD.
Software são os programas e sistemas que funcionam no computador. Dois exemplos são o Windows e o Google Chrome.
Em resumo: hardware é a parte física; software é a parte dos programas e sistemas.
3. Principais componentes e suas funções

CPU (processador): é responsável por executar instruções e realizar os cálculos necessários para o funcionamento do computador.
Memória RAM: é uma memória temporária utilizada para manter os dados e programas que estão sendo usados naquele momento. Uma quantidade adequada de RAM ajuda o computador a executar várias tarefas simultaneamente. desempenho em várias tarefas ao mesmo tempo.
HD ou SSD: é usado para armazenar arquivos, documentos, fotos, programas e o sistema operacional. O SSD costuma ser mais rápido que o HD.
Periférico: é um equipamento conectado ao computador que permite entrada ou saída de informações. Um exemplo é o teclado, utilizado para inserir textos e comandos.

4. Boas práticas de segurança

Use uma senha forte: a senha deve ser difícil de adivinhar, evitando nomes, datas de nascimento ou combinações muito simples. Sempre que possível, utilize autenticação em dois fatores.
Faça backup regularmente: mantenha cópias dos arquivos importantes em um local seguro. No setor, recomenda-se realizar o backup pelo menos uma vez por semana.
Tenha cuidado ao navegar: não clique em links desconhecidos, evite baixar arquivos de sites suspeitos e mantenha o sistema e o antimalware atualizados.
Cuidado com golpes: desconfie de mensagens que pedem senhas, dinheiro, dados pessoais ou que apresentam links e arquivos inesperados. Antes de clicar, confirme se a mensagem realmente veio de uma fonte confiável.

## 5. Interpretação do Anexo I

A orientação principal do Anexo I é proteger os arquivos e as contas do setor contra perda de dados e ameaças digitais. Para isso, é necessário fazer backup semanal, manter o antimalware atualizado, utilizar senhas fortes e verificar mensagens antes de abrir links desconhecidos.
Backup é uma cópia de segurança dos arquivos. Ele permite recuperar documentos caso sejam apagados, danificados ou perdidos.
Malware é um programa criado para causar algum tipo de dano ou realizar ações maliciosas em um computador, como roubar informações ou prejudicar arquivos. Vírus e alguns tipos de programas espiões são exemplos de malware.
Autenticação é o processo de verificar se uma pessoa realmente é quem diz ser para permitir o acesso a uma conta ou sistema. Um exemplo comum é entrar em uma conta usando usuário e senha.
Em uma linguagem simples, a mensagem do Anexo I quer dizer: faça uma cópia dos arquivos importantes toda semana, mantenha o programa de proteção do computador atualizado, use uma senha segura e nunca abra links de mensagens suspeitas sem antes verificar se são confiáveis. Essas atitudes ajudam a evitar a perda de arquivos, o roubo de informações e outros problemas de segurança.

## Conclusão

Organizar os arquivos e conhecer os equipamentos e programas utilizados é importante para melhorar o trabalho do setor. Ao mesmo tempo, atitudes simples, como fazer backup semanal, utilizar senhas fortes, manter o antimalware atualizado e desconfiar de mensagens suspeitas, ajudam a proteger as informações da empresa. Com essas práticas, todos os funcionários podem contribuir para um ambiente de trabalho mais organizado e seguro.
