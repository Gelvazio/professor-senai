# Como organizar e proteger o computador do setor
## Problema e solução
O computador do setor pode apresentar problemas quando os arquivos ficam desorganizados, quando não há cópias de segurança ou quando ele é usado de maneira insegura. Para evitar perda de informações, golpes e vírus, é importante organizar os arquivos, manter os programas atualizados, fazer backup e ter cuidado ao usar a Internet.
## Hardware e software
Hardware é a parte física do computador, ou seja, aquilo que podemos tocar. Exemplos de hardware são o teclado e o SSD.
Software é a parte formada pelos programas e sistemas que fazem o computador funcionar. Exemplos de software são o Windows e o navegador de Internet.
## Principais componentes
CPU: é o processador do computador. Ele executa as instruções e realiza os cálculos necessários para os programas funcionarem.
Memória RAM: armazena temporariamente os dados dos programas que estão sendo usados. Ela ajuda o computador a funcionar de forma mais rápida.
HD ou SSD: serve para guardar arquivos, programas e o sistema operacional. O SSD geralmente é mais rápido que o HD.
Periférico: é um equipamento conectado ao computador. Um exemplo é o mouse, usado para movimentar o cursor e selecionar opções.
## 4 boas práticas de segurança
Usar senha forte: criar senhas difíceis de descobrir, evitando nomes e datas de nascimento. Sempre que possível, usar autenticação em dois fatores.
Fazer backup: manter cópias dos arquivos importantes para evitar a perda de informações.
Navegar com segurança: evitar sites desconhecidos, não clicar em links suspeitos e manter os programas atualizados.
Cuidar com golpes: desconfiar de mensagens que pedem senhas, dinheiro ou informações pessoais. Antes de clicar em um link, verificar se ele é realmente confiável.
## Termos do Anexo I
Backup: é uma cópia de segurança dos arquivos. Ele permite recuperar os dados caso sejam apagados ou perdidos.
Malware: é um programa malicioso que pode causar problemas no computador ou roubar informações. Vírus são um exemplo.
Autenticação: é a forma de confirmar a identidade de uma pessoa antes de permitir o acesso a uma conta ou sistema, como acontece quando usamos uma senha
