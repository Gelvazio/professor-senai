Na empresa AgroSoft, a equipe de qualidade está avaliando um sistema de gestão agrícola. Para garantir que os requisitos sejam atendidos, os testes são realizados analisando somente as entradas fornecidas e as saídas geradas pelo sistema, sem conhecimento da lógica interna ou do código-fonte.

Qual é o tipo de teste descrito acima? 


Teste de Cobertura de Código.
Teste de Caixa Branca.
Teste de Caminho.
Teste de Caixa Preta.


Na empresa InovaSoft, a equipe de engenharia de software está desenvolvendo um sistema de agendamento médico. Para assegurar a qualidade do produto e o alinhamento com os requisitos definidos, a equipe decide aplicar o Modelo V de teste.

Qual o foco dessa metodologia de teste? 

Garantir que o sistema seja testado no final do ciclo de desenvolvimento, sem etapas de validação intermediárias.
Validar os requisitos de negócios ao longo de todo o ciclo de desenvolvimento, com ênfase na verificação em cada fase.
Concentra-se na execução de testes manuais, sem envolver testes automatizados.
Focar em testes de desempenho no final do ciclo de desenvolvimento.


Em uma fábrica automotiva, está sendo desenvolvido um sistema de monitoramento das linhas de montagem. Durante o processo de criação, os programadores avaliam trechos específicos do código em separado, assegurando que cada parte cumpra sua função antes de integrar ao restante do sistema.



O teste unitário é realizado para verificar a integração de diferentes módulos do sistema.
O teste unitário foca em validar a funcionalidade de unidades pequenas e isoladas do código, como funções ou métodos.
O teste unitário é aplicado após a conclusão do sistema, sem testes em fases anteriores de desenvolvimento.
O teste unitário exige testes manuais, sem o uso de ferramentas automatizadas.


Em uma indústria farmacêutica de Santa Catarina, está em desenvolvimento um sistema de gestão de qualidade. Esse sistema é composto por diferentes módulos: um para cadastro de colaboradores e normas de segurança, outro para o processamento de treinamentos obrigatórios e um terceiro responsável pela emissão de relatórios com alertas de prazos vencidos. Após validar cada módulo separadamente, a equipe de testes avança para uma nova etapa, na qual realiza os testes de integração.

Qual é o objetivo deste teste? 

Verificar se cada módulo do sistema funciona de forma isolada.
Medir a performance do sistema, como o tempo de resposta e a estabilidade sob carga.
Garantir que os módulos do sistema interagem e que as informações sejam transferidas.
Simular o uso real do sistema, validando se o fluxo de trabalho atende às necessidades do usuário.


A equipe da DevSecurity foi contratada para testar o módulo financeiro de um e-commerce. Para garantir que a lógica interna do código esteja correta e sem desvios, o analista de testes utiliza o código-fonte da aplicação para elaborar os cenários, analisando estruturas condicionais, laços de repetição e caminhos de execução.

Qual técnica de teste está sendo aplicada nesse cenário?

Teste de Caixa Preta.
Teste de Caixa Branca.
Teste de Usabilidade.
Teste de Carga.

A plataforma MegaVendas se prepara para uma grande promoção de fim de ano. Temendo que o servidor caia devido ao alto volume de acessos simultâneos, a equipe de TI realiza simulações para medir o tempo de resposta do sistema e verificar seu comportamento sob estresse e alta demanda de usuários.

Qual é o tipo de teste descrito na situação?

Teste de Desempenho (ou Carga).
Teste Regressivo.
Teste Unitário. 
Teste de Segurança. 


A empresa AgilSoft desenvolveu um sistema de gestão escolar para uma rede municipal. Antes de homologar o sistema e realizar a entrega final, a equipe convocou os próprios diretores e secretários das escolas para operarem o sistema em um ambiente simulado, validando se o software atende às necessidades reais do seu dia a dia.

Como é classificado o teste realizado pelos usuários finais? 

Teste de Integração.
Teste de Aceitação do Usuário (UAT).
Teste de Caixa Branca.
Teste de Estresse.


Durante o desenvolvimento de um aplicativo mobile de entregas, os desenvolvedores utilizam scripts automáticos que executam a suite de testes a cada alteração feita no código. Isso permite identificar erros minutos após serem cometidos, sem a necessidade de intervenção humana a cada nova compilação. 

Qual é a principal vantagem da automação de testes demonstrada na situação? 

Eliminar a necessidade de documentação do sistema.
Substituir todos os testes de aceitação feitos pelo cliente final.
Executar testes de forma rápida, repetível e integrada ao processo de desenvolvimento.
Garantir que o sistema não apresente mais falhas na produção.


Em uma indústria de laticínios, o sistema de automação envia alertas quando a temperatura dos tanques sai da faixa ideal (entre 2°C e 8°C). Ao planejar os testes, o analista decide testar especificamente os valores 1°C, 2°C, 8°C e 9°C para verificar se o sistema decide corretamente quando emitir os alertas.

Qual técnica de teste de caixa preta foi utilizada pelo analista? 

Teste de Estresse.
Análise do Valor Limite.
Teste de Mutação.
Teste de Caminho Básico. |
