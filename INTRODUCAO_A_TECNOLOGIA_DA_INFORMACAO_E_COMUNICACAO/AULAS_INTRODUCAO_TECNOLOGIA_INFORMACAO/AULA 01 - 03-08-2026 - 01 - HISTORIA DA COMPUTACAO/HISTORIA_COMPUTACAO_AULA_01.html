Como Surgiram os Computadores?

🧮Séc. XVIIÁbaco e Pascalina — primeiros instrumentos de cálculo mecânico criados pelo homem
⚙️1837Charles Babbage projeta a "Máquina Analítica" — considerado o pai do computador
🏛️1940sENIAC (1945) — primeiro computador eletrônico digital, ocupava uma sala inteira e pesava 30 toneladas
🔬1950–60Transistores e circuitos integrados substituem válvulas — computadores ficam menores e mais baratos
💾1970sMicroprocessador (Intel 4004, 1971) — todo o processador em um único chip de silício
🖥️1980sPC pessoal — IBM PC (1981) e Apple Macintosh (1984) chegam às casas e escritórios
📱HojeSmartphones, nuvem e IA — bilhões de dispositivos conectados, computadores na palma da mão

As 5 Gerações dos Computadores

💡1ª GeraçãoVálvulas eletrônicas (1940–56) — enormes, caríssimos, superaqueciam; usados por governos e universidades
🔋2ª GeraçãoTransistores (1956–63) — menores, mais rápidos e confiáveis; surgem as primeiras linguagens de programação
📟3ª GeraçãoCircuitos integrados (1963–71) — múltiplos transistores em um chip; surgem os sistemas operacionais
💻4ª GeraçãoMicroprocessadores (1971–presente) — PC pessoal, internet, smartphones — era que vivemos hoje
🤖5ª GeraçãoInteligência Artificial (em desenvolvimento) — computadores aprendem, reconhecem voz e imagem, tomam decisões
💡 Cada geração tornou os computadores menores, mais rápidos, mais baratos e acessíveis a mais pessoas.

Como Funciona um Computador (PC)?

  • Entrada: o usuário insere dados por teclado, mouse, microfone, câmera ou sensores
  • Processamento: a CPU (processador) executa instruções — é o "cérebro" do computador
    • Realiza milhões de operações matemáticas e lógicas por segundo
    • A velocidade é medida em GHz (gigahertz)
  • Memória RAM: armazena temporariamente os dados em uso — quanto mais RAM, mais rápido
  • Armazenamento (HD/SSD): guarda os arquivos permanentemente — mesmo após desligar o PC
  • Saída: o resultado é exibido no monitor, impresso, enviado para alto-falantes ou para a rede
  • Software: conjunto de instruções (programas) que dizem ao hardware o que fazer
    • 🔁 Resumo: Entrada → Processamento → Armazenamento → Saída — ciclo básico de qualquer computador.

Hardware — Componentes Internos e Periféricos

  • Hardware: toda parte física do computador — tudo que se pode tocar e ver
  • Componentes internos (dentro do gabinete):
    • CPU (Processador): executa instruções — Intel Core, AMD Ryzen; velocidade em GHz
    • Memória RAM: armazena dados temporários em uso — quanto mais, melhor o desempenho
    • HD / SSD: armazenamento permanente de arquivos e programas; SSD é muito mais rápido
    • Placa-mãe: placa principal que conecta todos os componentes entre si
    • Placa de vídeo (GPU): processa imagens e vídeos — essencial para jogos e edição
    • Fonte de alimentação: converte e fornece energia elétrica para os componentes
  • Periféricos de entrada: teclado, mouse, microfone, câmera, scanner, leitor de código de barras
  • Periféricos de saída: monitor, impressora, alto-falante, projetor
    • 💡 Um computador sem hardware não existe — sem software, não faz nada. Os dois dependem um do outro.

Software — Tipos e Características

  • Software: conjunto de programas, instruções e dados que dizem ao hardware o que fazer — é a parte lógica (intangível) do computador
  • Software de Sistema (Base):
    • Sistema Operacional (Windows, Linux, macOS, Android, Chrome OS) — gerencia o hardware e é a base para os demais programas
    • Drivers — programas que permitem ao SO se comunicar com o hardware (impressora, placa de vídeo...)
    • Firmware — software embutido em chips de dispositivos (BIOS, roteadores, impressoras)
  • Software Aplicativo: programas para tarefas específicas do usuário
    • Produtividade: Google Docs, Excel, Word, LibreOffice
    • Comunicação: Gmail, WhatsApp, Google Meet, Zoom
    • Entretenimento: Spotify, Netflix, jogos digitais
  • Software Embarcado: instalado em equipamentos industriais — CLPs, robôs, sistemas de automação
  • Licenças: Proprietário (pago, ex.: Windows) · Livre/Open Source (gratuito, ex.: Linux) · Freeware (grátis, mas fechado)

O que são Algoritmos?

  • Algoritmo: sequência finita e ordenada de passos para resolver um problema ou executar uma tarefa
  • Todo programa de computador é, na essência, um algoritmo escrito em linguagem de programação
  • Características de um bom algoritmo:
    • Finito: tem início, meio e fim definidos
    • Claro: cada passo é preciso e sem ambiguidade
    • Correto: produz o resultado esperado para qualquer entrada válida
    • Eficiente: usa o mínimo de recursos (tempo e memória)
  • Exemplo do dia a dia — algoritmo para fazer café:
    • 1. Colocar água na chaleira → 2. Ferver a água → 3. Colocar o pó no filtro → 4. Coar a água quente → 5. Servir
  • Na indústria: algoritmos controlam máquinas, processos de produção e sistemas de segurança

Linguagens de Programação

  • O que são: conjunto de regras e símbolos que permitem escrever instruções que o computador entende e executa
  • O computador só entende binário (0 e 1) — as linguagens traduzem o que escrevemos para essa linguagem
Python 🐍Fácil de aprender, usada em IA, ciência de dados e automação
JavaScript 🌐Linguagem da web — faz páginas interativas no navegador
Java ☕Usada em apps Android, sistemas bancários e corporativos
C / C++ ⚙️Alta performance — usada em sistemas operacionais e jogos
SQL 🗄️Linguagem para consultar e gerenciar bancos de dados
HTML/CSS 🎨Linguagens de marcação e estilo de páginas web
Hoje existem mais de 700 linguagens de programação — cada uma tem um propósito e contexto de uso.

Sistemas Operacionais e Tipos de Software

  • Sistema Operacional (SO): programa que gerencia o hardware e permite que outros programas funcionem
    • Windows (Microsoft) — mais usado em PCs pessoais e corporativos
    • Linux — open source, muito usado em servidores e sistemas industriais
    • macOS (Apple) — para computadores Mac, foco em design e criação
    • Android / iOS — sistemas para smartphones e tablets
    • Chrome OS — sistema do Chromebook, focado na nuvem (Google)
  • Software Aplicativo: programas para tarefas específicas — Word, Excel, Photoshop, Chrome
  • Software Embarcado: programas dentro de máquinas e equipamentos industriais — robôs, CLPs, sensores
  • Software Livre (Open Source): código aberto, qualquer pessoa pode usar, modificar e distribuir

Onde os Sistemas de TI são Usados?

  • Indústria: controle de linhas de produção, robótica, CLP (Controlador Lógico Programável), SCADA, automação industrial
  • Saúde: prontuários eletrônicos, tomógrafos, monitoramento de pacientes, cirurgia robótica, telemedicina
  • Educação: plataformas EAD, jogos educativos, lousa digital, bibliotecas digitais, Google Classroom
  • Finanças: internet banking, Pix, bolsa de valores, sistemas antifraude, gestão fiscal
  • Transporte: GPS, semáforos inteligentes, piloto automático, rastreamento de frota, metrô automatizado
  • Agronegócio: drones, irrigação inteligente, monitoramento de safras por satélite, controle de estoque
  • Segurança Pública: câmeras com reconhecimento facial, sistemas de emergência, comunicação policial
  • Cotidiano: streaming (Netflix), redes sociais, apps de entrega, assistentes de voz (Google, Alexa)

A Evolução da Web — de 1991 até Hoje

🌐1991 — Web 1.0Tim Berners-Lee cria a World Wide Web no CERN · Páginas estáticas, somente leitura · Primeiros navegadores: Mosaic (1993) e Netscape · Conteúdo publicado apenas por empresas e instituições
🛒1994–2003Boom da Internet · Amazon (1994), Yahoo! (1995), Google (1998) surgem · E-commerce começa a crescer · Bolha das ".com" estoura em 2000 · Banda larga substitui o dial-up
👥2004 — Web 2.0Web participativa e colaborativa · Facebook (2004), YouTube (2005), Twitter (2006), Wikipedia · Qualquer pessoa publica conteúdo · iPhone (2007) leva a web ao bolso · Apps, streaming e redes sociais dominam
🔗2008 — BlockchainBitcoin criado por Satoshi Nakamoto · Registro descentralizado e imutável · Ethereum (2015): contratos inteligentes · Criptomoedas e NFTs surgem como ativos digitais
🤖2015+ — Web 3.0Web inteligente e descentralizada · IA generativa: ChatGPT (2022), Gemini, Copilot · Datacenters globais: AWS, Azure, Google Cloud · IoT: bilhões de dispositivos conectados · Nuvem, metaverso e realidade aumentada
💡 A Web não parou de evoluir: a Web 3.0 promete uma internet mais descentralizada, inteligente e controlada pelos próprios usuários.
