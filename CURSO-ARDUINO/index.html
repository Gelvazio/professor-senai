O que é Arduino?
  • Plataforma open-source de prototipagem eletrônica
  • Combina hardware (placa + microcontrolador) e software (IDE + linguagem)
  • Criado para facilitar o aprendizado de eletrônica para não-engenheiros
  • Usado em projetos de automação, robótica, IoT e arte interativa
  • Comunidade global com milhões de projetos compartilhados gratuitamente
Definição simples: É um computador minúsculo que você programa para controlar componentes eletrônicos — LEDs, motores, sensores e muito mais.
🔑 Características
  • Open-source (hardware e software)
  • Baixo custo (a partir de R$ 30)
  • Grande variedade de modelos
  • Enorme comunidade e suporte
  • Compatível com centenas de shields
  • IDE disponível para Windows, Mac e Linux
📖 História do Arduino
  • 2003 — Origem no Instituto de Design de Interação de Ivrea, Itália
  • 2005 — Massimo Banzi, David Cuartielles e outros criam o Arduino como projeto de TCC
  • 2005 — Primeira placa lançada ao público com licença open-source
  • 2010 — Arduino ganha popularidade mundial na comunidade maker
  • 2015 — Lançamento do Arduino Zero (ARM Cortex-M0+)
  • 2016 — Arduino Cria LLC (US) e Arduino AG (Suíça) se unem
  • 2019 — Arduino Nano Every, MKR WiFi 1010
  • 2024 — Mais de 30 milhões de placas vendidas no mundo
🌍 Impacto Global
  • Usado em mais de 100 países
  • Presente em universidades, escolas e fablabs
  • Base para projetos da NASA e Tesla
Curiosidade: O nome "Arduino" vem de um bar em Ivrea, Itália, onde os criadores se reuniam frequentemente durante o desenvolvimento do projeto.

Arduino UNO R3
Modelo mais popular. Ideal para iniciantes. 14 pinos digitais, 6 analógicos. ATmega328P.

Arduino MEGA 2560
54 pinos digitais, 16 analógicos. Mais memória. Ideal para projetos complexos.

Compacto e barato. Mesma capacidade do UNO em tamanho reduzido. Perfeito para wearables.
🟥

Pode ser reconhecido como mouse/teclado USB. ATmega32u4 com USB nativo.
🟪
Arduino MKR WiFi
Com Wi-Fi integrado. Ideal para projetos IoT e conexão com internet.
⬛
Arduino Due
ARM Cortex-M3, 84 MHz. Alta performance. 54 pinos digitais e DAC nativo.
💻 Linguagem de Programação
O Arduino usa uma linguagem baseada em C e C++, simplificada pelo framework Wiring. É a linguagem de programação de baixo nível mais ensinada no mundo.
  • Sintaxe derivada do C e C++ padrão
  • Adicionada biblioteca Wiring para facilitar controle de hardware
  • Funções prontas: digitalWrite(), analogRead(), delay()
  • Compilado com avr-gcc para linguagem de máquina
  • Todo código C/C++ válido funciona no Arduino
C / C++ Hardware Open Source
Exemplo de código
// Pino do LED const int led = 13; // Executado uma vez ao ligar void setup() { pinMode(led, OUTPUT); Serial.begin(9600); } // Loop eterno void loop() { digitalWrite(led, HIGH); delay(1000); digitalWrite(led, LOW); delay(1000); }

📐 Estrutura de um Programa Arduino
  • Todo programa Arduino é chamado de sketch
  • Dois blocos obrigatórios: setup() e loop()
  • setup() — roda apenas uma vez ao ligar ou resetar
  • loop() — roda infinitamente após o setup
  • Variáveis globais ficam fora das funções
  • Ponto-e-vírgula obrigatório ao final de cada instrução
Dica: Pense no setup() como as regras do jogo e no loop() como o jogo em si, que nunca para.
// === VARIÁVEIS GLOBAIS === int contador = 0; bool ativo = true; // === SETUP (executa 1x) === void setup() { Serial.begin(9600); pinMode(13, OUTPUT); Serial.println("Iniciando..."); } // === LOOP (executa sempre) === void loop() { contador++; Serial.println(contador); delay(500); }
📍 Pinos: Digital e Analógico
⚡ Pinos Digitais
  • Trabalham com apenas 2 estados: HIGH (5V) ou LOW (0V)
  • No UNO: pinos 0 a 13
  • Pinos com ~ são PWM (pseudo-analógico): 3, 5, 6, 9, 10, 11
  • Funções: digitalRead() e digitalWrite()
pinMode(13, OUTPUT); // configura digitalWrite(13, HIGH); // liga LED int btn = digitalRead(7); // lê botão
📊 Pinos Analógicos
  • Leem tensões de 0V a 5V com resolução de 10 bits (0–1023)
  • No UNO: pinos A0 a A5
  • Ideais para sensores contínuos: temperatura, luz, potenciômetro
  • Função: analogRead()
int valor = analogRead(A0); // valor entre 0 e 1023 Serial.println(valor);

✨ Projeto 1: LED Piscando (Blink)
📋 O QUE VOCÊ PRECISA
  • 1x Arduino UNO
  • 1x LED (qualquer cor)
  • 1x Resistor 220Ω
  • 1x Protoboard
  • Jumpers (fios)
  • Cabo USB para o Arduino
Montagem: LED → pino 13 do Arduino com resistor de 220Ω em série. GND no negativo do LED.
🎯 RESULTADO: LED acende e apaga a cada 1 segundo
Código completo
/* Blink — Pisca LED no pino 13 Projeto 1 — Início do Arduino */ const int LED_PIN = 13; void setup() { pinMode(LED_PIN, OUTPUT); } void loop() { digitalWrite(LED_PIN, HIGH); delay(1000); // aguarda 1s digitalWrite(LED_PIN, LOW); delay(1000); // aguarda 1s }
📡 Sensores Mais Usados
  • DHT11/DHT22 — Temperatura e umidade do ar
  • HC-SR04 — Distância por ultrassom (robótica)
  • PIR — Detecção de presença por infravermelho
  • LDR — Resistor dependente de luz (fotoresistor)
  • MPU-6050 — Acelerômetro e giroscópio (3 eixos)
  • DS18B20 — Temperatura via OneWire, à prova d'água
  • MQ-2 / MQ-7 — Gás, fumaça e monóxido de carbono
  • RFID RC522 — Leitura de cartões e tags sem fio
🎓 Exemplo: DHT11
#include <DHT.h> DHT dht(2, DHT11); void setup() { Serial.begin(9600); dht.begin(); } void loop() { float t = dht.readTemperature(); Serial.println(t); delay(2000); }
🔗 Comunicação Serial
  • Permite enviar e receber dados pelo Monitor Serial da IDE
  • Essencial para depuração de código
  • Velocidade configurável: 9600, 115200 baud
  • Também usada para comunicação entre módulos (Bluetooth HC-05, GPS)
  • Pinos: TX (1) e RX (0) no Arduino UNO
Monitor Serial: Abra com Ctrl+Shift+M na IDE. Configure o baud rate igual ao do código.
void setup() { Serial.begin(9600); } void loop() { // Envia texto Serial.println("Olá Arduino!"); // Recebe dado do PC if (Serial.available()) { char c = Serial.read(); Serial.print("Recebido: "); Serial.println(c); } delay(1000); }
📚 Bibliotecas do Arduino
  • Bibliotecas são pacotes de código prontos para usar com sensores e módulos
  • Instaladas pelo Gerenciador de Bibliotecas da IDE (Ctrl+Shift+I)
  • Mais de 5.000 bibliotecas disponíveis gratuitamente
  • Inclusas com #include <nome.h> no código
Dica: Ao pesquisar um módulo no Google, adicione "Arduino library" para encontrar a biblioteca certa.
